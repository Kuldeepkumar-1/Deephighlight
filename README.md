# \# DeepHighlight

# 

# \*\*A Chrome Extension for Google Sheets\*\*

# 

# DeepHighlight is a Chrome Extension designed to improve the Google Sheets working experience through real-time row, column, and crosshair highlighting.

# 

# \## Features

# 

# \- Real-time row and column highlighting

# \- Crosshair highlighting for better cell tracking

# \- Non-destructive highlighting

# \- Customizable extension settings

# \- Lightweight Chrome Extension

# \- Manifest V3 support

# \- Persistent settings using Chrome Storage Sync

# 

# \## Installation

# 

# 1\. Download or clone this repository.

# 2\. Open Google Chrome.

# 3\. Navigate to `chrome://extensions/`.

# 4\. Enable Developer Mode.

# 5\. Click \*\*Load unpacked\*\*.

# 6\. Select the extracted `deephighlight` project folder.

# 

# \## Project Structure

# 

# \- `manifest.json` – Extension configuration

# \- `background.js` – Background service worker

# \- `content.js` – Main content script

# \- `highlight.js` – Highlighting functionality

# \- `observer.js` – DOM observation

# \- `overlay.js` – Highlight overlay rendering

# \- `storage.js` – Settings storage

# \- `toolbar.js` – Google Sheets toolbar integration

# \- `popup.html/js/css` – Extension popup

# \- `options.html/js/css` – Extension settings

#
